# 手機版 K 棒複盤系統

## 啟動（Windows / macOS / Linux）

1. 解壓縮 ZIP，打開 `mobile-k-replay` 資料夾。
2. 電腦安裝 Node.js（最低 18，建議使用仍受支援的 LTS 版本）。
3. 在此資料夾開啟終端機，執行：

```sh
npm start
```

4. 用瀏覽器開啟 http://127.0.0.1:8080 。關閉時在終端機按 Ctrl+C。

沒有第三方 npm 依賴，不需要 npm install，也不需要 API 金鑰或 .env。
請透過 HTTP 伺服器開啟，不能直接雙擊 index.html，否則內建行情的 fetch 可能失敗。

若已有 Python 3，也可在專案根目錄執行：

```sh
python -m http.server 8080 --bind 127.0.0.1 --directory dist
```

## 手機測試

電腦和手機需連上同一個 Wi-Fi。Windows PowerShell 執行：

```powershell
$env:HOST="0.0.0.0"
npm start
```

macOS / Linux：`HOST=0.0.0.0 npm start`。
手機開啟 `http://電腦區域網路IP:8080`，必要時允許私人網路防火牆存取。
此啟動器只用於本機開發；正式上線請以 HTTPS 靜態網站服務發布 dist 資料夾。

## 專案內容與依賴

- `dist/index.html`：畫面結構。
- `dist/style.css`：手機版樣式。
- `dist/app.js`：圖表、播放、交易、停損與互動的完整可編輯原始碼。
- `dist/csv.js`：CSV 解析。
- `dist/storage.js`：瀏覽器 IndexedDB 資料保存。
- `dist/data/`：完整內建行情 JSON，依月份分檔及索引。
- `dist/icon-*.png`、`dist/manifest.webmanifest`：圖示與網頁應用設定。
- `server.cjs`、`package.json`：使用 Node.js 內建模組的開發伺服器與啟動指令。

前端使用瀏覽器原生 Canvas、Fetch、IndexedDB，沒有框架、CDN 或第三方套件。
`dist` 在本專案就是可直接修改的原始碼，不需要編譯或建置。
執行 `npm run check` 可檢查 JavaScript 語法。

## 資料與功能

內建行情為原專案的小台日盤一分 K，共 192,420 根、643 個交易日，範圍 2024-02-01 至 2026-10-01。
交易損益設定為微台：每點 10 元，單邊每口手續費 23 元，市價滑價 5 點。
支援 1 / 5 / 30 分 K、單根／動態播放、當日模式、買賣模擬、可拖曳停損線及 CSV 匯入。
使用者另外匯入的 CSV 儲存在該瀏覽器的 IndexedDB；手機或另一個網址的私人瀏覽器資料不在此 ZIP 中，需重新匯入。

## iPhone 主畫面 App 與離線使用

正式使用請將 `dist/` 發布到 HTTPS 靜態網站，保持同一個網址，並確保 `sw.js` 以 JavaScript 類型提供且不要求登入重新導向。用 Safari 開啟網站，點上方「App」可查看加入主畫面步驟與離線準備狀態。Safari 分享 → 加入主畫面 → 開啟「打開為網頁 App」（若有）→ 加入。加入後從主畫面圖示開啟，使用獨立視窗及 iPhone 安全區域。

首次保持連網，直到 App 說明顯示「離線準備完成」。系統會快取畫面及全部 33 個月份的內建行情，之後可離線開啟、換日期與模擬交易。若 iPhone 清除網站資料或回收空間，需連網重新準備。加入主畫面後若沒有 Safari 中自行匯入的 CSV，請再匯入；請保留 CSV 原檔。

`dist/pwa.js` 管理安裝說明及離線狀態；`dist/sw.js` 管理離線快取。修改內建資源時，請遞增 `CACHE_NAME` 的版本。更新在下次連網開啟時取得，不會清除 IndexedDB 匯入資料。主畫面安裝及 iPhone 系統觸控行為仍需實機確認。

## 當日複盤的縮放與全日切換

「當日」模式只限制顯示的交易日，不會強制縮放。雙指張開放大、合攏縮小，同時調整 K 棒寬度及價格比例，以兩指中間的行情為縮放中心，移動兩指也可平移視窗；放開後保留視角與手動比例，不會跳回最右側或重新置中價格。直向、橫向全螢幕、1／5／30 分 K 與分時圖沿用同一套操作。單指仍可拖曳回看，按「最新」回到最新行情並置中一次，之後水平接續播放、價格範圍維持不動；只有自動播放時已揭露且顯示於目前視窗的當日行情高低點越界時，才擴大價格範圍並留邊距，不會自動縮回，也不改 K 棒寬度。手動縮放／拖曳期間及回看歷史時不會強制拉回；分時圖沿用相同規則。

「全日」按一下進入自動縮放，完整顯示當天已走出的 K 棒，後續播放時持續調整；再次點擊，恢復進入前的手動大小，將最新 K 棒靠右、最新價格置中。全日狀態會亮起，且不會提前顯示未來行情。全日狀態下直接縮放會從目前顯示的視角進入手動模式，保留兩指中間的行情位置。1／5／30 分各自保留視窗與全日切換狀態。

工具列移至圖表上方，不覆蓋行情。圖表下方顯示成交量柱狀圖，與價格共用時間定位、縮放和平移；1／5／30 分 K 依週期累計已揭露的量，分時圖使用當日每分鐘量。未來分鐘不參與顯示或成交量高度計算；未完成分鐘的動態量依播放進度估算，標示「模擬」。橫向全螢幕保留價格與成交量，工具列沿用隱藏規則。

## 當日分時複盤

圖表上方的「分時」可切換當日分時線，再按一次回到原本的 K 棒週期。切換不會清除交易或改變播放進度，並記住下次開啟時的圖表選擇。分時圖只畫出已播放的每分鐘收盤價及動態模式的當前模擬價格；前日行情與未來價格都不會顯示，也不會用於自動調整價格軸。分時與 K 棒使用相同的雙指縮放、單指平移、價格軸／時間軸調整、最新與全日切換操作；兩種圖表分別保存視窗。全日自動顯示當天已播放的價格線，再次點擊恢復手動大小，最新價格靠右並置中。買賣、停損及收盤平倉沿用原有規則。

## 水平線與手機橫向版面

圖表下方「水平線」每點一次新增一條可編輯的虛線，並鎖定上一條線。按住虛線上下拖曳，拖線時暫停播放及固定圖表，放開後恢復原播放狀態；取消觸控則還原原價格。點圖表空白處將虛線轉為實線並鎖定；雙擊實線重新解鎖編輯。實線不攔截圖表拖曳與縮放，沒有價格標籤或單條刪除按鈕；使用「清除線」一次刪除目前日期的全部標記，不影響其他日期或交易。水平線價格及鎖定狀態依資料來源、檔名與日期保存在 IndexedDB，K 棒／分時圖共用。舊版保存的標記自動視為已鎖定。

手機橫向時，圖表延伸到左右安全區域之間的完整寬度；損益、播放及買賣控制集中在底部，取消原本右側交易面板。橫向控制區縮減留白，較寬的手機將損益與操作集中為一列，以增加圖表高度，數字字級保持不變。直向版面維持原本配置。

## 橫向全螢幕圖表

橫向時，點上方四角圖示進入圖表全畫面模式，隱藏一般工具與交易面板，只在右下保留等大的播放／暫停、收盤、買／賣、下一根按鈕及本次合計損益（已實現＋浮動，沿用滑價與手續費）。正數紅色，負數綠色；平倉後仍可看到累計結果。右上小圖示取消全螢幕偏好；轉直向暫回一般介面，再轉橫向自動恢復。偏好會在目前瀏覽器保存，直向不提供進入按鈕。K 棒、分時、觸控縮放與播放進度沿用原狀態；全螢幕僅顯示已鎖定的水平線，不提供編輯或清除；請回一般模式操作。五鍵依序為 ▶／Ⅱ、收、買、賣、→，各鍵維持原本窄版尺寸，高度不變；買／賣隱藏口數副標籤，仍每次一口。全畫面買賣左側的 ▶／Ⅱ 使用同一個播放邏輯，可直接開始、暫停及在當日結束後接續下一個交易日；退出全畫面後也會同步原本播放按鈕的狀態。「收」沿用一般模式的收盤功能，停止播放、揭露當日剩餘行情並依原有停損與成交規則結算持倉；「→」先暫停再依目前 1／5／30 分週期前進一根，分時圖前進一分鐘。手動縮放或平移後，逐根前進保留目前價格範圍與時間視窗，不會為納入前一天的 K 棒而縮小；新 K 棒向右接續，到右側後才捲動，回看歷史時則保留該區段。自動播放仍可依當日已揭露行情越界擴大，前日價格不參與手動視窗的擴大計算。動態模式會完成當前形成中的 K 棒，不改變播放模式；當日結束時收盤及下一根停用，播放仍可接續下一交易日。

此功能將圖表擴展至 App 可用畫面，不依賴 iPhone Safari 未全面支援的網頁 Fullscreen API。從加入主畫面的 App 開啟可避免 Safari 網址列占用空間。

## iPhone 旋轉與系統指示條

頁面固定文字縮放比例，表單選單維持至少 16px，避免 Safari 小字表單取得焦點時自動放大；App 頁面使用固定 1 倍的 viewport 縮放限制，App 區域阻止瀏覽器原生雙指與雙擊放大；圖表內的雙指縮放及雙擊線條解鎖仍由圖表自己的事件處理。旋轉後會重新套用 1 倍的頁面設定。橫直向切換會在視窗尺寸穩定後重算 App 高度、取消未完成的拖曳並關閉表單焦點。背景與安全區域統一為深色。

iPhone 螢幕最下方中央的固定白色短橫條是 iOS 主畫面指示條，由系統繪製；網頁無法移除。此環境的瀏覽器測試可驗證尺寸與互動邏輯，但 Safari 原生自動縮放及主畫面指示條仍需 iPhone 實機確認。

連續複盤到下一交易日時，水平線會以相同價格帶入並鎖定，與新一天原有標記合併；不會覆蓋已經編輯過的同一條線。清除後不再帶入後續日期。手動選日期或隨機跳日仍使用該日自己的標記，原日期保存的線不會被刪除。水平線不參與自動縮放或全日模式的價格範圍，超出視窗時仍會保存，可手動縮放或平移查看。重播、選日與接續下一交易日保留當前手動 K 棒寬度與價格比例，位置回到最新行情並以新一天首次揭露的價格置中一次，之後不隨最新價格上下移動；分時圖亦同。若已選擇「全日」，換日後繼續依已揭露行情自動調整，不會因遠處的水平線拉遠。
