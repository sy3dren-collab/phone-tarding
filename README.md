# 手機版 K 棒複盤系統

## 啟動（Windows / macOS / Linux）

1. 解壓縮 ZIP，打開 `mobile-k-replay` 資料夾。
2. 電腦安裝 Node.js（最低 18，建議使用仍受支援的 LTS 版本）。
3. 在此資料夾開啟終端機，執行：

```sh
npm start
```

4. 用瀏覽器開啟 http://127.0.0.1:8080 。關閉時在終端機按 Ctrl+C。

沒有第三方 npm 依賴，不需要 npm install，也不需要 API 金鑰或 .env。
請透過 HTTP 伺服器開啟，不能直接雙擊 index.html，否則內建行情的 fetch 可能失敗。

若已有 Python 3，也可在專案根目錄執行：

```sh
python -m http.server 8080 --bind 127.0.0.1 --directory dist
```

## 手機測試

電腦和手機需連上同一個 Wi-Fi。Windows PowerShell 執行：

```powershell
$env:HOST="0.0.0.0"
npm start
```

macOS / Linux：`HOST=0.0.0.0 npm start`。
手機開啟 `http://電腦區域網路IP:8080`，必要時允許私人網路防火牆存取。
此啟動器只用於本機開發；正式上線請以 HTTPS 靜態網站服務發布 dist 資料夾。

## 專案內容與依賴

- `dist/index.html`：畫面結構。
- `dist/style.css`：手機版樣式。
- `dist/app.js`：圖表、播放、交易、停損與互動的完整可編輯原始碼。
- `dist/csv.js`：CSV 解析。
- `dist/storage.js`：瀏覽器 IndexedDB 資料保存。
- `dist/data/`：完整內建行情 JSON，依月份分檔及索引。
- `dist/icon-*.png`、`dist/manifest.webmanifest`：圖示與網頁應用設定。
- `server.cjs`、`package.json`：使用 Node.js 內建模組的開發伺服器與啟動指令。

前端使用瀏覽器原生 Canvas、Fetch、IndexedDB，沒有框架、CDN 或第三方套件。
`dist` 在本專案就是可直接修改的原始碼，不需要編譯或建置。
執行 `npm run check` 可檢查 JavaScript 語法。

## 資料與功能

內建行情為原專案的小台日盤一分 K，共 192,420 根、643 個交易日，範圍 2024-02-01 至 2026-10-01。
交易損益設定為微台：每點 10 元，單邊每口手續費 23 元，市價滑價 5 點。
支援 1 / 5 / 30 分 K、單根／動態播放、當日模式、買賣模擬、可拖曳停損線及 CSV 匯入。
使用者另外匯入的 CSV 儲存在該瀏覽器的 IndexedDB；手機或另一個網址的私人瀏覽器資料不在此 ZIP 中，需重新匯入。

## iPhone 主畫面 App 與離線使用

正式使用請將 `dist/` 發布到 HTTPS 靜態網站，保持同一個網址，並確保 `sw.js` 以 JavaScript 類型提供且不要求登入重新導向。用 Safari 開啟網站，點上方「App」可查看加入主畫面步驟與離線準備狀態。Safari 分享 → 加入主畫面 → 開啟「打開為網頁 App」（若有）→ 加入。加入後從主畫面圖示開啟，使用獨立視窗及 iPhone 安全區域。

首次保持連網，直到 App 說明顯示「離線準備完成」。系統會快取畫面及全部 33 個月份的內建行情，之後可離線開啟、換日期與模擬交易。若 iPhone 清除網站資料或回收空間，需連網重新準備。加入主畫面後若沒有 Safari 中自行匯入的 CSV，請再匯入；請保留 CSV 原檔。

`dist/pwa.js` 管理安裝說明及離線狀態；`dist/sw.js` 管理離線快取。修改內建資源時，請遞增 `CACHE_NAME` 的版本。更新在下次連網開啟時取得，不會清除 IndexedDB 匯入資料。主畫面安裝及 iPhone 系統觸控行為仍需實機確認。

## 當日複盤的縮放與全日切換

「當日」模式只限制顯示的交易日，不會強制縮放。雙指張開放大、合攏縮小，同時調整 K 棒寬度及價格比例；播放時維持手動比例，最新 K 棒靠右，價格置中。單指仍可拖曳回看，按「最新」恢復跟隨並保留縮放比例。

「全日」按一下進入自動縮放，完整顯示當天已走出的 K 棒，後續播放時持續調整；再次點擊，恢復進入前的手動大小，將最新 K 棒靠右、最新價格置中。全日狀態會亮起，且不會提前顯示未來行情。全日狀態下直接縮放也會回到手動模式。1／5／30 分各自保留視窗與全日切換狀態。

## 當日分時複盤

圖表下方的「分時」可切換當日分時線，再按一次回到原本的 K 棒週期。切換不會清除交易或改變播放進度，並記住下次開啟時的圖表選擇。分時圖只畫出已播放的每分鐘收盤價及動態模式的當前模擬價格；前日行情與未來價格都不會顯示，也不會用於自動調整價格軸。分時與 K 棒使用相同的雙指縮放、單指平移、價格軸／時間軸調整、最新與全日切換操作；兩種圖表分別保存視窗。全日自動顯示當天已播放的價格線，再次點擊恢復手動大小，最新價格靠右並置中。買賣、停損及收盤平倉沿用原有規則。

## 水平線與手機橫向版面

圖表下方「水平線」每點一次新增一條可編輯的虛線，並鎖定上一條線。按住虛線上下拖曳，拖線時暫停播放及固定圖表，放開後恢復原播放狀態；取消觸控則還原原價格。點圖表空白處將虛線轉為實線並鎖定；雙擊實線重新解鎖編輯。實線不攔截圖表拖曳與縮放，沒有價格標籤或單條刪除按鈕；使用「清除線」一次刪除目前日期的全部標記，不影響其他日期或交易。水平線價格及鎖定狀態依資料來源、檔名與日期保存在 IndexedDB，K 棒／分時圖共用。舊版保存的標記自動視為已鎖定。

手機橫向時，圖表延伸到左右安全區域之間的完整寬度；損益、播放及買賣控制集中在底部，取消原本右側交易面板。橫向控制區縮減留白，較寬的手機將損益與操作集中為一列，以增加圖表高度，數字字級保持不變。直向版面維持原本配置。
